# Region A: 0x7000000000 to 0x70005fffff (module main)

Written from the local index only (`tools/map_find.py region`, `near`, `fn`, `str`; `work/map/index/*.jsonl`). No generated C was read and the game was not run. Tags: [C] confirmed by a string, SDK symbol or documented fact; [I] inferred from a strong pattern of neighbouring strings and callers; [H] guess.

## Summary

This 6 MB block holds about 15,200 of the game's functions and is the most mixed region in `main`. Its lower half (0x7000000000 to about 0x7000300000) holds the core match simulation and AI: fielders chasing and throwing the ball, runners leading off and advancing, pitch timing, the batter's contact model, and the catcher and umpire state machines. Its middle (about 0x7000300000 to 0x7000400000) holds more fielding and runner behaviour, then the audio stream system. The upper part (0x7000400000 to 0x70004fffff) holds the Road To The Show and franchise UI, stats, player and stadium data fields, and save handling. The top (0x7000500000 to 0x70005fffff) holds the Dear ImGui debug UI, the memory allocator, the NVN graphics driver and kick wait, the Scream audio synth, and a class-registration framework. Scattered through it are third-party libraries: an ASTC texture decoder, tinyexr, nlohmann JSON, stb_image, the msdfgen/mesh-repair code for the field distance texture, and Dear ImGui. The region is a map of subsystems, not of single functions; most individual function meanings below are [I].

## Vtables

The vtables file lists 6125 tables. About 700 of them have at least three functions in this region. Only the ones whose functions reveal a role are listed.

- **119-slot AI class family, about 40 copies in the 0x700216xxxx data area.** Each table holds 119 function pointers whose first entries sit at 0x70000b7d34 to 0x70000bb2bc (the window at 0x7000080000 to 0x7000100000) and share a common slot at 0x70000b8170. The functions have no callers in the index, which fits virtual dispatch. Nearby strings name roles: "ONLINE AI BATTER", "ONLINE RUNNER DECISION", "GRIFFEY REANALYZE PITCH", "SUPPORT", "PUPPET", "ACT_Slot1Out", "Loco Ring". Tag [I]: one base class with many role subclasses (batter, runner, pitcher, support) for the AI decision layer. The exact class names are not in the index.
- **1025-slot table at 0x700215c000.** Its first entries are in this region (210 of them). No class name was found in the index. Tag [H]: a large interface or dispatch table. Not examined further.
- **Flux framework (0x70005c0000 window).** `FluxClassBroker_T`, `Method_Broadcaster`, `FluxDependency`, `FluxGroup`, `Method_RecurseGroup`, `ClassBroker`. A template comment reads "Cut and paste this in for the most minimal Class". Tag [C] for the names, [I] for a class-registration and method-dependency system.
- **Vtable density by window.** Counting tables with at least three functions in the window where their first function sits, the densest windows are 0x7000300000 (91 tables), 0x7000080000 (73), 0x70004c0000 (70), 0x7000540000 (57) and 0x70003c0000 (56). Window 0x7000300000 is the fielding and runner block; 0x70004c0000 is the save and UI block.
