# Region main+0x1000000 to main+0x13fffff (0x7001000000-0x70013fffff)

This page covers 16 windows of 256 KB, about 4 MB, of module `main`, where most of the game's "match flow" logic lives. Index-based notes only: generated C was read for vtable structure and string-bearing handlers, and most of the lifted code was not read. Tags: [C] confirmed by a string, SDK symbol or documented fact; [I] inferred from a strong pattern; [H] guess.
