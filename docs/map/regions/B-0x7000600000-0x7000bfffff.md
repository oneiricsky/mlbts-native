# Region B: 0x7000600000 to 0x7000bfffff (module main)

Region B of `main` is 0x7000600000 to 0x7000bfffff: 6 MB in 24 windows of 256 KB each, holding between about 430 and 1,540 functions per window. Addresses are 1.0.20.

It was read from the address index and from the region's strings, callers, callees and vtable slots. The generated C was not read for any function here and no function was run.

Tags: [C] confirmed by a string, SDK symbol or documented fact shown in the index; [I] inferred from a strong pattern (neighbouring strings, callers, vtable roles); [H] guess, not checked.

## Summary

| Part | Where | What it holds |
|---|---|---|
| Whole region | 6 MB, 24 windows of 256 KB | Between about 430 and 1,540 functions per window; most of the region's functions are still only known by their strings |
| Eastern half | Upper windows | Online and Diamond Dynasty code: party and matchmaking, network sessions, login, a texture download state machine, a player-creation vault upload, and mini-season and challenge rewards |
| Western half | Lower windows | The offline game: the create-player and presentation (cutscene) front end, roster moves, franchise setup, the UI widget library, and the league and player data tables |
| First window | 0x7000600000 | A reflection and serialization layer (a "Flux" archive plus a bundled JSON library), which the rest of the game uses to read and write its data files |
| Last window | 0x7000bc0000 | The Road to the Show attribute, token and perk screens |
| Brief addresses | 0x70008dc5b0, 0x7000a32ce0 | Not function entry points in the index, so they are not examined here |
