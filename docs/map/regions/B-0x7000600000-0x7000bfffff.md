# Region B: 0x7000600000 to 0x7000bfffff (module main)

Map note, 1.0.20 addresses. Tags: [C] confirmed by a string, SDK symbol or documented fact shown in the index;
[I] inferred from a strong pattern (neighbouring strings, callers, vtable roles); [H] guess, not checked.

## Summary

This region is 6 MB of the game (24 windows of 256 KB, each holding between about 430 and 1,540 functions). Its eastern half is online and Diamond Dynasty code: party and matchmaking, network sessions, login, a texture
download state machine, a player-creation vault upload, and mini-season and challenge rewards. The western half is
the offline game: the create-player and presentation (cutscene) front end, roster moves, franchise setup, the UI
widget library, and the league and player data tables. The very first window holds a reflection and serialization
layer (a "Flux" archive plus a bundled JSON library), which the rest of the game uses to read and write its data
files. The Road to the Show attribute, token and perk screens sit in the last window. The two addresses in the brief
that look like the universal profile's tutorial code (0x70008dc5b0, 0x7000a32ce0) are not function entry points in
the index, so they are not examined here. Most of the region's functions are still only known by their strings.
