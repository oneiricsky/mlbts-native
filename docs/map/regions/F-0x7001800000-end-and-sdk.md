# Region F: main 0x7001800000 to end of text, and the sdk module

This page covers the last part of `main` (0x7001800000 to 0x7001c22800, 14,539 generated functions) and the whole
`sdk` module (40,069 functions, 19,260 with real names). It was built from the local index (`work/map/index/`) with
`tools/map_find.py`, not from reading code: no function bodies were read in full and the game was not run. Every
section below is a table; the tag legend comes first.

## Tag legend

| Tag | Meaning |
|---|---|
| [C] | confirmed: a string, SDK symbol, or documented fact shows it directly |
| [I] | inferred: strong pattern |
| [H] | guess |

## Summary

| Part | Extent | Contents | Note |
|---|---|---|---|
| Game logic | first half of the range | frontend, player and stats database, in-game substitution and inning logic | — |
| Compiled-in libraries | after the game logic | JSON parser (nlohmann), libcurl HTTP stack, video decoder (Bink) | third-party code |
| Sony audio stack | 0x7001a80000 to 0x7001c00000 | SCREAM audio middleware and a DSP effects graph | — |
| End of the range | — | C library and allocator (malloc, free) plus about 733 small "import thunks" | thunks are tiny code stubs that jump through a table to functions supplied by the SDK |
| `sdk` module | — | Nintendo's SDK 19.3.11: most named code is the `nn::` system services (audio, file system, input, accounts, network), then the C++ runtime, a C library, image and zlib code, and the NVIDIA GPU driver layer | — |
| NVN (graphics API) | small named area near 0x70050b0000 to 0x70050f0bb0 | graphics API implementation | its main entry points have no names, so which game code calls which NVN function is not yet known |
