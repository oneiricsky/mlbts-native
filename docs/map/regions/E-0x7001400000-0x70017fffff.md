# Region E: 0x7001400000 to 0x70017fffff (module main)

This 4 MB range is mostly the game's own code, with one large standard library in the middle. It holds 17,451 functions in 16 windows of 256 KB each, read from the local index (`work/map/index/`) rather than from any file layout, and the generated C was opened for only a few functions. Tags: [C] confirmed by a string, SDK symbol or direct structure; [I] inferred from a strong pattern; [H] guess. Reading upward in address order gives animation and the engine's base object layer, then game objects and the studio's online-services client, then OpenSSL, then the game's own content layer. The band boundaries come from where the string families change, so they are approximate to within a few 16 KB blocks.
